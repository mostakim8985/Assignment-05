   ## - 1️⃣ What is the difference between var, let, and const?
    var: var is global scoped. can be re-declared and reassigned.
    let: let is block scoped. cannot be re-declared but can be reassigned.
    const: const is block scoped. cannot be re-declared or reassigned and must be initialized when declared.
   ## - 2️⃣ What is the spread operator (...)?
    ANS:
    The spread operator is used to expand elements of an array or object into individual elements .
   ## - 3️⃣ What is the difference between map(), filter(), and forEach()?
    ANS:
    map(): Create a new array by transforming each element of the original array.
    filter(): Create a new array with elements that match a condition.
    forEach(): Executes a function for each array element but does not return a new array.
   ## - 4️⃣ What is an arrow function?
    ANS:
    An arrow function is a shorter way to write functions in JavaScript using the => syntax.
    It provides a more concise syntax and does not have its own this context.

   ## - 5️⃣ What are template literals?
    Template literals are a way to create strings using backticks (` `) instead of quotes.
     They allow embedding variables and expressions using ${} and support multi-line strings.
